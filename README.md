## 📌 Sobre o Projeto

O **Xhopii** é um sistema web de e-commerce desenvolvido como Trabalho Prático da disciplina de **Técnicas Avançadas de Programação Web e Mobile** da FATEC.

O objetivo do projeto é construir um sistema completo de loja virtual utilizando apenas tecnologias **front-end puras**, com foco em boas práticas de desenvolvimento e fidelidade ao design proposto.

---

## 🎯 Objetivos

* Desenvolver interfaces modernas de e-commerce
* Aplicar conceitos de:

  * HTML semântico
  * CSS avançado
  * Flexbox
  * Grid Layout
* Criar um sistema visual semelhante a marketplaces reais
* Trabalhar organização e estrutura de código

---

## 🚀 Tecnologias Utilizadas

* ✅ HTML5 (Obrigatório)
* 🎨 CSS3
* 📦 Flexbox
* 🧩 CSS Grid Layout
* 🎞️ Bootstrap (apenas para o carrossel)

---

## 📸 Funcionalidades

## 🎨 Layout

O sistema segue um padrão visual inspirado em grandes marketplaces como:

* Produtos organizados em **Grid Layout**
* Cards com hover interativo
* Layout centralizado e responsivo
* Uso de cores modernas (ex: laranja estilo e-commerce)

## 📱 Responsividade

O projeto foi desenvolvido com foco em responsividade:

```css
@media (max-width: 768px) {
    .produtos {
        grid-template-columns: 1fr 1fr;
    }
}
```
